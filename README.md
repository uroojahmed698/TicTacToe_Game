Tic Tac Toe Game

A simple two-player Tic Tac Toe game developed in Java using Java Swing. The project features a graphical user interface with interactive buttons that allow players to take turns and play directly through the application window.

Features

Graphical user interface built with Java Swing.

Interactive buttons for selecting spaces on the game board.

Two-player gameplay.

Alternating turns between Player X and Player O.

Traditional 3×3 Tic Tac Toe board.

Technologies Used

Java – Application logic and game functionality.

Java Swing – Graphical user interface and interactive buttons.

Eclipse IDE – Development environment.

How to Run

Clone or download this repository.

Open Eclipse or similar IDE.

Import the project into your workspace.

Locate the main Java class containing the main method.

Run the class as a Java Application.

Play using the buttons on the game board.
